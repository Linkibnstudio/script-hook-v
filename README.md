## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Native Access** | Exposes the full GTA V native function table to mod scripts |
| **ASI Loader** | Automatically loads all ASI plugins from the game directory |
| **Script Runtime** | Manages mod script threads alongside the game's own systems |
| **Trainer Included** | Comes with a built-in trainer for quick single-player testing |
